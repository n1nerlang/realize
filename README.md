# Realize - Minimalist Bedrock UI

**Realize** is a performance-focused, minimalist UI resource pack designed for Minecraft: Bedrock Edition. Built with modern Render Dragon optimization principles, it replaces legacy bloat with clean, sharp, and high-performance assets.

## Features
*   **Minimalist Aesthetic:** Flat-colored, low-noise textures designed for maximum visual clarity.
*   **Performance Optimized:** Clean UI structure that reduces draw calls and eliminates legacy anchor bugs.
*   **Render Dragon Ready:** Engineered for 1.21.30+ to ensure sharp, anti-aliased menu navigation.
*   **Clean Borders:** Precisely defined UI elements to reduce eye strain.

## Installation
1. Download the latest `.mcpack` file from the [Releases](https://github.com/n1nerlang/realize/releases) page.
2. Open the file to automatically import it into Minecraft.
3. Activate "Realize" in your Global Resources or World Settings.

## Technical Specifications
*   **Engine Version:** 1.21.30+
*   **Resolution:** 16x16 standard
